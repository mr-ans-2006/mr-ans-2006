### Projects

**[Yaad](https://github.com/mr-ans-2006/yaad)** (یاد, "memory"): a privacy-first Android app that remembers your screenshots. It reads the text in each new screenshot on the phone (ML Kit OCR), embeds it with a small MiniLM model, and lets you search by meaning plus exact words. It has no internet permission, no account and no server. Built in Kotlin with Jetpack Compose and Room, with the search logic in a pure-Kotlin module covered by unit tests.

**[SindhiScript](https://github.com/mr-ans-2006/SindhiScript)**: a programming language written entirely in Sindhi. It's a tree-walking interpreter in Python, with its own lexer, recursive-descent parser and evaluator. It supports functions, classes with inheritance, try/catch, modules, a Python interop block and a browser-based IDE built for right-to-left text.

**[▶ Try SindhiScript live](https://mr-ans-2006.github.io/SindhiScript/)**

```
ڪم فيڪٽوريل(ن):
    جيڪڏهن ن گهٽ_برابر 1:
        موٽايو 1
    موٽايو ن ضرب فيڪٽوريل(ن گهٽائڻ 1)
```

**[Sindhi Typing Master](https://github.com/mr-ans-2006/Sindhi-Typing-Master)**: a MonkeyType-style typing test for Sindhi. It pulls real text from Sindhi Wikipedia and shows live WPM, accuracy, a speed graph and a heatmap of the letters you miss. Built in vanilla JavaScript with Vite.
